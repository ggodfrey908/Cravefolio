# Cravefolio
A restaurant rewards dashboard in development.

## Preview
Open `index.html` in a browser. No build step required.

## Important
All reward balances and cards are illustrative. This starter does not access restaurant accounts, process sign-ups, or synchronize rewards. `data/integration-status.json` records research status only.

## Deploying
This folder can be committed to a separate GitHub repository and used as the root of a Cloudflare Pages static project. Do not invite real customers to connect accounts until authentication, privacy controls, and approved integrations have been implemented and tested.
